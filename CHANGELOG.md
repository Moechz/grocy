# Changelog

All notable user-visible changes to the Grocy TOS application package.

## 4.7.1-1 — 2026-11-15

### Added
- First release. Grocy (`linuxserver/grocy:4.7.1`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8175 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/grocydocker/`.
